# Third-party software and camera compatibility

EOS 1300D Recorder Studio is an unofficial community project. It is not affiliated with, endorsed by, or supported by Canon. Canon, EOS, Rebel and other product names identify the devices and software with which this project interoperates.

The MIT license covers this project's source code. It does not grant rights to Canon software. **Canon EDSDK, EOS Utility and their DLLs are not included in the repository or release package.** Install compatible Canon software separately from Canon, under its own terms.

The application uses Windows, .NET Framework, WPF and the public Canon SDK interface. Interop declarations describe the interface; no Canon SDK implementation is shipped. The app icon is original, generated by the build script.

The camera implementation was tested on a physical Canon EOS 1300D, firmware 1.1.0. Rebel T6 and Kiss X80 are regional names for the same camera family; those branded units have not been separately hardware-tested. Other EOS models are intentionally rejected.
